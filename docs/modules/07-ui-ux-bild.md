# Модуль 7 — UI/UX кабинета бильда

**Статус:** in_progress  
**Зависимости:** [04-api-web.md](04-api-web.md), [06-yandex-disk.md](06-yandex-disk.md)

## Цель

Сделать кабинет бильда удобным для ежедневной работы без изменения рабочего backend-процесса:

- быстро понять, где новые пачки;
- легко скачать или открыть альтернативный источник (Я.Диск зеркало);
- уверенно работать с телефона/планшета в полевых условиях.

## План первого прохода

1. [x] Привести карточки пачек к устойчивой визуальной иерархии.
2. [x] Добавить фильтрацию/поиск по фотографу и времени.
3. [x] Улучшить состояния кнопок (`loading/success/error`) для действий.
4. [x] Упрощённый мобильный layout (одноколоночный, крупные tap-зоны).
5. [x] Просмотр оригинала фото в модальном окне поверх галереи.
6. [ ] Собрать обратную связь от 2-3 бильдов и зафиксировать правки.

## Что уже внедрено в этом модуле

- Верхняя навигация вкладками: `Пакеты` (по умолчанию), `Уведомления`, `Настройки`.
- Для продуктового режима сценариев 1+2 пакетный экран упрощён:
  - убраны фильтры/поиск/ручная очистка списка;
  - показываются только актуальные пакеты, реально лежащие в `incoming`.
- Явные действия по жизненному циклу пачек:
  - `Скачать все`;
  - `Скачать выбранное`;
  - чекбоксы выбора фото в галерее;
  - `Загрузить на Я.Диск`.
- Оптимизация производительности просмотра:
  - превью не из оригиналов, а через thumbnail endpoint;
  - загрузка картинок с ограниченной конкуренцией;
  - защита от лишних перерисовок (меньше мерцаний).
- UX просмотра оригинала:
  - lightbox поверх галереи;
  - переходы `пред/след` кнопками и клавиатурой;
  - закрытие по `Esc`/вне области;
  - скачивание одного файла из lightbox.
- Устойчивость сессии:
  - единая обработка `401` (очистка токена, остановка polling, переход в `Настройки`).

## Что осталось на финиш UI/UX

1. Провести короткий smoke-тест на 2-3 реальных пользователях-бильдах.
2. Зафиксировать и внедрить небольшие правки по их обратной связи.
3. Подтвердить на живых сценариях корректность удаления:
   - `Скачать все` удаляет все файлы пакета из `incoming`;
   - `Скачать выбранное` удаляет только выбранные файлы.

## Ограничение этапа

На этом модуле не меняем ingestion/watcher/DB-архитектуру, только UI/UX-слой и мелкие API-поля при необходимости.
