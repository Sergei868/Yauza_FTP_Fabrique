# Модуль 7 — UI/UX кабинета бильда

**Статус:** in_progress  
**Зависимости:** [04-api-web.md](04-api-web.md), [06-yandex-disk.md](06-yandex-disk.md)

## Цель

Сделать кабинет бильда удобным для ежедневной работы без изменения рабочего backend-процесса:

- быстро понять, где новые пачки;
- легко скачать или открыть альтернативный источник (Я.Диск зеркало);
- уверенно работать с телефона/планшета в полевых условиях.

## План первого прохода

1. [x] Привести карточки пачек к устойчивой визуальной иерархии.
2. [x] Добавить фильтрацию/поиск по фотографу и времени.
3. [x] Улучшить состояния кнопок (`loading/success/error`) для действий.
4. [x] Упрощённый мобильный layout (одноколоночный, крупные tap-зоны).
5. [x] Просмотр оригинала фото в модальном окне поверх галереи.
6. [ ] Собрать обратную связь от 2-3 бильдов и зафиксировать правки.

## Ограничение этапа

На этом модуле не меняем ingestion/watcher/DB-архитектуру, только UI/UX-слой и мелкие API-поля при необходимости.
